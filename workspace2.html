Source dataset
Surfaces are patient-derived 3D transoesophageal echocardiography segmentations (MVSeg 2023), in native millimetres. All geometry below is measured from the mesh, not prescribed.
Source scale calibration
The source STL files carry no units. Nothing in the dataset records the voxel spacing of the 3D TEE volumes they were reconstructed from, so this factor is an explicit assumption — every length, area and volume reported by this tool scales with it.
Detected anatomical frame
The annular plane, commissural axis and anterior side are derived automatically: the annulus is recovered as the wide cut rim, its normal by plane fit, the commissural axis by principal-axis analysis of the ring, and the anterior leaflet identified as the taller of the two halves (geodesic height from the annulus).
Mesh working resolution
Uniform vertex-clustering decimation. Lower values raise frame rate; measurements change by well under 1 mm² across this range.
Lesion model coaptation deficit
Regurgitation is produced geometrically: the closing leaflets are held short of their coaptation target, and the resulting orifice is then measured by planimetry each frame. Nothing about the leak is prescribed.

Diastolic excursion model parameter
Not derived from the segmentationThe source surface is a single instant of the cardiac cycle showing a closed valve, so it contains no information about how far the leaflets swing open. Mitral valve area and the diastolic gradient therefore depend on this setting; the regurgitant orifice, which is measured from the closed geometry, does not.

Left heart represented by a time-varying-elastance ventricle, elastic atrium and three-element Windkessel aorta. Mitral flow is computed from the orifice equation using the measured valve area, so pressures, gradient and regurgitant volume are all emergent.

Colour-Doppler scale
Velocities above the Nyquist limit alias (wrap) exactly as in clinical colour Doppler — the mosaic core of the regurgitant jet is expected, not an artefact.
Flow convergence PISA
The radius at which the hemispherical convergence velocity equals the Nyquist limit — that is, the PISA shell this valve would present on echo. This is a forward prediction, not an independent check on the orifice: the convergence field is generated from the regurgitant orifice, so inverting it can only return the same value. Clinically PISA is independent because it is measured from images.
